# TaOₓ 1T1R 忆阻器存算一体：可运行的软件仿真原型

> 用于“忆阻器存算一体 + 钠离子电池 + AIDC 能效优化”黑客松的第一阶段：**器件行为级 AI 推理验证**。不是完整芯片或数据中心能耗仿真。

## 为什么选 TaOₓ？

Abedin 等人在 2023 年发表于 *Scientific Reports* 的对比研究中，使用 65 nm CMOS 集成的 TaOₓ 与 HfOₓ 1T1R 阻变单元。特定实验条件下，TaOₓ 达到 35 个可区分的电导状态、对应低端电导约 9.8 µS；相比该研究的 HfOₓ 器件，低电导使 TaOₓ 具有更低的阵列导通能耗潜力。该论文的研究任务偏向模拟在线训练，本项目仅借用材料参数构建**离线训练/阵列内推理**模拟，不能复现或直接套用论文训练准确率。

- 文献：Abedin M, et al. *Material to system-level benchmarking of CMOS-integrated RRAM with ultra-fast switching for low power on-chip learning*. Scientific Reports **13**, 14963 (2023).
- DOI：https://doi.org/10.1038/s41598-023-42214-x

## 软件做了什么？

1. 加载 `scikit-learn` 自带的 digits 数据集，训练 64→32→10 MLP，建立浮点数字计算基线。
2. 把两层权重映射为差分的 `G+ / G−` 电导矩阵，模拟正负权重的存储。每个电导用 35 个离散状态近似。
3. 通过 `I = V × G` 的阵列运算模拟前向推理，包括电导编程误差和 ADC 量化。
4. 扫描 ADC 为 6 / 8 / 10 bit（以及理想不量化情形）和器件编程误差标准差为 0 / 2 / 5 / 10% 电导跨度，重复 3 次。
5. 生成数字识别准确率、阵列电阻耗散及演示性 ADC/DAC 能耗分解结果。

### 数学原理

- 差分权重编码：`W = Wscale × (G+ − G−)/(Gmax−Gmin)`。
- 阵列电流：`I_j = Σ_i V_i G_ij`，差分输出 `I_j+ − I_j−`。
- 阵列导通能耗估计：`E_array = t_read × Σ_i V_i² Σ_j (G+_ij + G−_ij)`。

### 仿真参数的证据等级

| 参数 | 本项目取值 | 依据 |
|---|---|---|
| 器件类型 | TaOₓ、1T1R | 2023 实验论文 |
| 电导状态数 | 35 | 该论文一种器件条件 |
| Gmin | 9.8 µS | 该论文与 35 状态对应的器件条件 |
| Gmax | 60 µS | **演示假设，需后续校准** |
| Vread | 0.10 V | **演示假设** |
| 读取持续时间 | 10 ns | **演示假设**，不得与论文中的 300 ps 编程脉冲混同 |
| ADC 单次能耗 | 2 pJ | **演示假设** |
| DAC 单次能耗 | 0.2 pJ | **演示假设** |
| 器件误差 std | 0/2/5/10% × (Gmax−Gmin) | **敏感性分析假设** |

注意：示例保持 ADC 单次能耗常数，不是实用 ADC 随位数变化的能耗模型。因此可对比**精度**随位数变化，但不能据此证明 ADC 位数与能耗的最优取值。

## 如何运行（Windows / Linux / macOS）

建议 Python 3.10+：

```bash
python -m pip install -r requirements.txt
python taox_cim_sim.py
```

你也可以改变随机种子和重复次数：

```bash
python taox_cim_sim.py --seed 42 --trials 5
```

运行后输出：

```text
results/
├── REPORT.md                   # 中文参数与结果说明
├── results.csv                 # 全部扫描结果
├── accuracy_vs_variation.png   # 器件误差 vs 准确率
└── modeled_energy_breakdown.png # 简化能耗分解
```

## 第一轮运行结果（seed=42、3 次重复）

- 数字浮点基准准确率：**97.56%**。
- TaOₓ 模型：8bit ADC，0% 器件误差：**97.56%**。
- TaOₓ 模型：8bit ADC，5% 器件误差：**95.56%**（重复实验标准差 1.27 个百分点）。
- TaOₓ 模型：8bit ADC，10% 器件误差：**90.74%**（重复实验标准差 4.06 个百分点）。
- 8bit ADC、0% 误差时，本模型的**局部能耗分解**：阵列 1.73 pJ/次、ADC 168 pJ/次（假设）、DAC 19.2 pJ/次（假设），合计约 188.93 pJ/次。

**不能把 188.93 pJ/次称为“整个 TaOₓ 芯片每次推理总能耗”，更不能和 GPU 全部能耗直接做节能率比较。** 1T 晶体管、驱动、电源转换、控制、存储数据搬运、阵列线路寄生、空闲功率、权重编程及系统延迟尚未建模。这只是一个严格限定范围的入门代理模型。

## 如何连接钠离子电池与 AIDC

本原型只构建了计算层。要验证赛题，下一阶段需：

1. 接入 **CrossSim**（https://cross-sim.sandia.gov/），完善器件误差、量化、互连寄生对**推理准确率**的影响；CrossSim 本身**不输出芯片级能耗、面积和速度**。
2. 接入 **NeuroSim**（https://github.com/neurosim/NeuroSim）或可校准的电路/芯片模型，估算完整存算推理加速器的能耗与延迟，并基于同任务对照数字计算。
3. 建立钠离子电池 `SOC + 可用能量 + 输出功率限制 + 转换效率` 模型。
4. 为同一工作负载构建数字计算、纯 CIM、能源感知异构调度 3 组公平实验，目标指标设为**满足推理精度与时延约束的任务数 / 电池实际输出电能**。
5. 有足够性能数据后，再扩展到更多 AIDC 应用工作负载和网络内计算模块。
